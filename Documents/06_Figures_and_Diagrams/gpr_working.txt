### STEP 3: MATÉRN KERNEL CONSTRUCTION
**Box color**: Purple header (#7B61FF)
**Label**: "Step 3 — Kernel Function k(x, x')"
**Code source**: `GaussianProcessEngine._construct_kernel()`

**Content inside the box:**

```
Composite Kernel:

  k(x, x') = σ²_f · k_Matérn(x, x')

Where:

  ┌─────────────────────────────────────────────────────────────────────┐
  │                                                                     │
  │  Matérn kernel (ν = 5/2):                                          │
  │                                                                     │
  │                    ┌           √5·d      5·d²  ┐        ┌  √5·d  ┐ │
  │  k_M(x,x') =  1 · │ 1  +  ────────  +  ─────  │ · exp  │- ─────  ││
  │                    │            l        3·l²   │        │    l    ││
  │                    └                            ┘        └        ┘ │
  │                                                                     │
  │  d = ‖x - x'‖₂  (Euclidean distance in scaled space)              │
  │  l = length_scale (optimized, init=1.0, bounds=[0.01, 100])        │
  │                                                                     │
  └─────────────────────────────────────────────────────────────────────┘

  ConstantKernel:
    σ²_f = signal variance (optimized, init=1.0, bounds=[0.001, 1000])

Code:
  ConstantKernel(1.0, (1e-3, 1e3)) * Matern(
      length_scale=1.0,
      length_scale_bounds=(1e-2, 1e2),
      nu=2.5
  )

Why ν = 2.5?
  → Twice differentiable (smooth but not infinitely smooth)
  → Ideal for physical manufacturing processes
  → More realistic than RBF (ν → ∞) for FDM data
```

### STEP 4: GPR TRAINING (LOG-MARGINAL-LIKELIHOOD OPTIMIZATION)
**Box color**: Orange header (#FFC107)
**Label**: "Step 4 — Model Training via MLE"
**Code source**: `gpr.fit(scaled_features, target_vector)`

**Content inside the box:**

```
Objective: Maximize the Log-Marginal-Likelihood

  log p(y | X̃, θ) = -½ · yᵀ(K + σ²_n·I)⁻¹y  -  ½·log|K + σ²_n·I|  -  n/2·log(2π)

  Where:
    K       = kernel matrix K(X̃, X̃)  ∈ ℝ^(n × n)     ← each entry is k(x̃ᵢ, x̃ⱼ)
    σ²_n    = noise variance (alpha = 0.01 in code)    ← regularization
    I       = identity matrix  ∈ ℝ^(n × n)
    θ       = {σ²_f, l}  (hyperparameters to optimize)
    n       = number of training points

  ┌──────────────────────────────────────────────────────────────────────┐
  │  Optimization: L-BFGS-B (gradient-based)                           │
  │  n_restarts_optimizer = 10 (avoids local minima)                   │
  │  random_state = 42 (reproducibility)                                │
  │                                                                      │
  │  Learns:                                                             │
  │    • σ²_f  → how much the function varies overall                   │
  │    • l     → how quickly correlations decay with distance            │
  └──────────────────────────────────────────────────────────────────────┘

This runs 3 TIMES — one independent GPR per output target:
  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
  │ GPR₁             │  │ GPR₂             │  │ GPR₃             │
  │ tension_strenght │  │ roughness        │  │ elongation       │
  │ (MPa)            │  │ (µm)             │  │ (%)              │
  └──────────────────┘  └──────────────────┘  └──────────────────┘

Code:
  gpr = GaussianProcessRegressor(kernel=..., n_restarts_optimizer=10, alpha=1e-2)
  gpr.fit(scaled_features, target_vector)
  train_r2 = gpr.score(scaled_features, target_vector)   # Training R²
```

**Arrow to next box**: "cross_val_score(gpr, X̃, y, cv=5)"

### STEP 5: 5-FOLD CROSS-VALIDATION
**Box color**: Cyan header (#00D4FF)
**Label**: "Step 5 — Model Validation (5-Fold CV R²)"
**Code source**: `cross_val_score(gpr, scaled_features, target_vector, cv=5, scoring='r2')`

**Content inside the box:**

```
Data is split into 5 folds:

  ┌──────┬──────┬──────┬──────┬──────┐
  │Fold 1│Fold 2│Fold 3│Fold 4│Fold 5│
  └──────┴──────┴──────┴──────┴──────┘

  Iteration 1: Train on [2,3,4,5]  → Test on [1]  → R²₁
  Iteration 2: Train on [1,3,4,5]  → Test on [2]  → R²₂
  Iteration 3: Train on [1,2,4,5]  → Test on [3]  → R²₃
  Iteration 4: Train on [1,2,3,5]  → Test on [4]  → R²₄
  Iteration 5: Train on [1,2,3,4]  → Test on [5]  → R²₅

               R²₁ + R²₂ + R²₃ + R²₄ + R²₅
  Mean CV R² = ─────────────────────────────────
                            5

                    Σ(yᵢ - ŷᵢ)²
  Where R² = 1  -  ─────────────
                    Σ(yᵢ - ȳ)²

  • R² = 1.0  → perfect prediction
  • R² = 0.0  → predicts the mean
  • R² < 0.0  → worse than the mean (underfitting — common with 25 rows)

Stored as:
  self.cv_metrics[target] = mean_cv        # e.g. {"tension_strenght": -0.277, ...}
  state["surrogate_r2_score"] = overall mean across all 3 targets
```

### STEP 6: POSTERIOR PREDICTION WITH UNCERTAINTY

**Label**: "Step 6 — GPR Posterior: µ(x*) ± σ(x*)"
**Code source**: `gpr.predict(scaled_features, return_std=True)`

**Content inside the box:**

```
For a new (unseen) input point x*:

  ┌─────────────────────────────────────────────────────────────────────────┐
  │                                                                         │
  │  Predictive Mean:                                                       │
  │    µ(x*) = k(x*, X̃) · [K(X̃, X̃) + σ²_n·I]⁻¹ · y                    │
  │                                                                         │
  │  Predictive Variance:                                                   │
  │    σ²(x*) = k(x*, x*) - k(x*, X̃) · [K(X̃, X̃) + σ²_n·I]⁻¹ · k(X̃, x*)│
  │                                                                         │
  │  Predictive Standard Deviation:                                         │
  │    σ(x*) = √σ²(x*)                                                     │
  │                                                                         │
  └─────────────────────────────────────────────────────────────────────────┘

  Interpretation (show as a bell curve / Gaussian illustration):

    • µ(x*) = "best guess" for the output value at this print setting
    • σ(x*) = "confidence" — HOW UNCERTAIN the model is at this point

    LOW σ  → model is confident (near training data)
    HIGH σ → model is uncertain (far from training data — EXPLORE HERE!)

  ┌─────────────────────────────────────────────────────┐
  │  Show a 2D plot sketch:                             │
  │                                                     │
  │    y ↑      ╭─── µ(x*) ± 2σ(x*) confidence band   │
  │      │   ╭──╯    (shaded area)                      │
  │      │  ╱ ●  ●                                      │
  │      │ ╱       ╲    ← wide band = high uncertainty  │
  │      │╱  ●      ╲                                   │
  │      ●────────────●──→ x                            │
  │      training      unexplored                       │
  │      points        region                           │
  └─────────────────────────────────────────────────────┘

Code (in Stage 04):
  mean_arr, std_arr = model.predict(x_scaled_for_pred, return_std=True)
  df_new[target_name]          = mean_arr     # predicted value
  df_new[f"_std_{target_name}"] = std_arr     # uncertainty

Stored in state:

      "tension_strenght": mean_sigma,

  }
```

### STEP 7: BAL ACQUISITION FUNCTION (MAX-VARIANCE + LOCAL PENALIZATION)
**Box color**: Red-Orange header (#FF6B35)
**Label**: "Step 7 — Bayesian Active Learning Acquisition"
**Code source**: `AcquisitionEngine._evaluate_objective()` + `execute_active_hunt()`

**Content inside the box (this is the largest box — show in detail):**

```
GOAL: Find the next 100 input points where the GPR is MOST UNCERTAIN
      → These are the most informative points to "query" next

═══════════════════════════════════════════════════════════════════
ACQUISITION FUNCTION:  α(x) = σ_total(x) · P(x)
═══════════════════════════════════════════════════════════════════

  PART A — Maximum Variance (Uncertainty Sampling):

    σ_total(x) = Σ σᵢ(x)     for i ∈ {tension, roughness, elongation}
                 ᵢ₌₁³

    → Sum the standard deviations from all 3 GPR models at point x
    → Points with the HIGHEST total σ are the most "interesting"

  ──────────────────────────────────────────────────────────────────

  PART B — Local Penalization (Batch Diversity):

    For the j-th point in the batch, penalize proximity to
    all previously selected points {x₁, ..., x_{j-1}}:

                     j-1
    P(x) = max(0,  1 - Σ  exp( -‖x - xₖ‖² / (2r²) ))
                     k=1

    Where:
      r = penalty_radius = 0.3 (in standardized space)
      ‖x - xₖ‖² = squared Euclidean distance to previously picked point

    → Gaussian "bump" repulsion around each already-selected point
    → Forces the batch to SPREAD OUT across the design space
    → Prevents the optimizer from picking 100 nearly-identical points

  ──────────────────────────────────────────────────────────────────

  COMBINED OBJECTIVE (minimized by differential_evolution):

    minimize  f(x) = -σ_total(x) · P(x)

    → Negative because scipy minimizes, but we want to MAXIMIZE uncertainty
    → P(x) ≈ 1 far from previous points (no penalty)
    → P(x) ≈ 0 near previous points (fully suppressed)

  ──────────────────────────────────────────────────────────────────

  OPTIMIZER: scipy.optimize.differential_evolution
    ┌─────────────────────────────────────────────┐
    │ Population-based evolutionary algorithm      │
    │ bounds = scaled space for each feature       │
    │ maxiter = 100                                │
    │ tol = 1e-4                                   │
    │ popsize = 8                                  │
    │ mutation = (0.5, 1.0)                        │
    │ recombination = 0.7                          │
    │                                              │
    │ Runs 100 TIMES per batch                     │
    │ (once per point, sequential greedy)          │
    └─────────────────────────────────────────────┘

  COLD START (iteration 0 only):
    → No GPR uncertainty map exists yet
    → Uses Sobol quasi-random sequence instead
    → Scrambled, low-discrepancy space-filling
    → Covers the 5D design space uniformly
```
