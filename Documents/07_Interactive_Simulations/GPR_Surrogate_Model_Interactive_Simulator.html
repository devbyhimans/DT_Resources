x* = the new print setting you're querying (e.g., nozzle temp °C) xᵢ = training data points (real Ultimaker S5 measurements) dᵢ = |x* − xᵢ| distance from query to training point i
k*(x*, xᵢ) = Matérn(ν=2.5) kernel similarity — how relevant point i is K = kernel matrix (all training-to-training similarities + WhiteKernel noise) α = K⁻¹ y = learned weights solved once from training data
μ(x*) = Σ kᵢ × αᵢ — the predicted mean output σ(x*) = √(σ²_f − k*ᵀ K⁻¹ k*) — the uncertainty (drives BAL) σ²_f = signal variance (ConstantKernel amplitude) σ²_n = noise variance (WhiteKernel — learned, not hardcoded)
